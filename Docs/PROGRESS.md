- **Đánh thử Phase 7.1 trên điện thoại** — pull code, build Dev, vào sân tập ▸ Đấu hình nộm + Đấu trường. Gửi tôi cảm nhận: ra đòn đã đủ nhanh chưa, vuốt có còn hay bị "sai" không, trận dài / ngắn thế nào. Số chỉnh ở `BattleConfig` / `SwipeConfig`.
- **Phase 7.2 / 7.3** — Thám hiểm (PvE) + nhiệm vụ ngày + đào kho báu (tôi làm tiếp).
- **Thử máy chủ** — chạy `dotnet run` trên Mac, điện thoại (bản Dev) gõ địa chỉ ở bảng DEV ▸ Máy chủ (`Docs/BUILD.md` mục 14). Gửi tôi:
  - Console / log nếu không nối được;
  - cảm giác độ trễ khi đánh PvP.
- **Phase 4.4** — Đưa máy chủ lên VPS (`Server/README.md` mục 3). **Cần bạn:** thuê VPS (Ubuntu, nên chọn Singapore) + 1 tên miền trỏ về VPS.
- **Thử thông báo** — build Dev, bật thông báo, bảng DEV ▸ Thông báo ▸ Thử sau 10 giây (`Docs/BUILD.md` mục 13). Gửi tôi ảnh thông báo trên máy.
- **Phase 4.5 phần FCM** — thông báo từ máy chủ (thưởng mùa, thách đấu...). Cần project Firebase + file cấu hình. Làm khi máy chủ đã lên VPS.
- **Phase 5.3** — Bạn build Android theo `Docs/BUILD.md`, gửi lỗi Console / log điện thoại + số fps. Tôi sửa theo kết quả, rồi làm tiếp:
  - đưa bản thử nội bộ lên Google Play (menu AAB + hướng dẫn đã có ở `Docs/BUILD.md` mục 15; cần tài khoản Play Console của bạn)
  - build iOS (cần Xcode)

## Ghi chú cho session sau

- Container cloud mới phải cài lại công cụ:
  `apt-get install -y --no-install-recommends blender python3-numpy dotnet-sdk-8.0`
- Chạy test logic: `dotnet test Tools/LogicTests` (khoảng 30 giây, gồm cả restore NuGet lần đầu).
- Test máy chủ: `dotnet test Server/PawFit.Server.Tests` (khoảng 10 giây, chạy máy chủ thật ở cổng ngẫu nhiên). Chạy thử máy chủ: `cd Server/PawFit.Server && dotnet run` (cổng 5080).
- Kiểm tra code logic theo bộ thư viện của Unity: `dotnet build Tools/NetStandardCheck` (.NET Standard 2.1). Code logic dùng API mới của .NET 8 thì bước này báo lỗi.
- Compile check nhánh chạy trên điện thoại (thông báo): `dotnet build Tools/UnityCompileCheck "-p:DefineConstants=UNITY_ANDROID%3BPAWFIT_NOTIFICATIONS" -o <thư mục tạm>`. Sau đó build lại thường bằng `--no-incremental`.
- Soát API package thông báo:
  - Tải tarball `com.unity.mobile.notifications-2.5.0.tgz` từ download.packages.unity.com (môi trường `gaao` đã mở packages.unity.com + cdn.packages.unity.com), giải nén vào thư mục tạm.
  - Chạy `python3 Tools/ApiAudit/api_audit.py Tools/UnityCompileCheck/UnityStubs.cs <thư mục>/package Unity.Notifications`.
- Đổi luật trận / tin nhắn mạng thì tăng `NetProto.Version` (`Online/Protocol.cs`): bản game cũ sẽ được báo "hãy cập nhật". Đang là 2 (Phase 7.1).
- Đo nhịp trận sau khi chỉnh số: `cd Tools/BattleBalance && dotnet run -c Release` (trận ngang sức nên ~25–30 giây).
- Máy chủ biên dịch chung `Core / Pet / Battle / Online`: thêm file logic mới vào 4 thư mục này là máy chủ có luôn; dùng `using` tới Garden / Economy trong Online sẽ làm hỏng build máy chủ.
- Compile thử code Unity: `dotnet build Tools/UnityCompileCheck` (stub ở `UnityStubs.cs`; dùng API Unity mới thì thêm stub).
- Môi trường cloud riêng `gaao` có setup script cài sẵn Blender + .NET + restore NuGet (chưa kiểm chứng ở session mới).
- `ProjectVersion.txt` đặt `6000.3.0f1`. Mở bằng bản 6.3 khác thì Unity tự cập nhật file này.
- Bản Blender của Ubuntu không có OpenImageDenoise, nên script đã tắt denoise.
- Xuất lại FBX: `blender -b --factory-startup --python Tools/Blender/export_kit.py -- Assets/PawFit/Resources/Pets/Gen1`, rồi kiểm tra bằng `blender -b --factory-startup --python Tools/Blender/check_kit.py` (phải ra `CHECK_RESULT PASS`). Mỗi lần xuất, repo nặng thêm khoảng 9 MB, nên chỉ xuất khi đổi model.
- Shader `Gen1Fur` / `Gen1Eye` viết tay cho URP 17 (Unity 6.3) và chưa chạy thử trong Unity thật (container không có Unity). Lỗi thì bảng DEV có nút chuyển sang URP Lit.
- Đổi số tiến hóa / chỉ số: `EvolutionConfig`, `StatsConfig` trong `GameConfig.cs`. Kinh tế: `EconomyConfig` (giá thuốc ở `HealthConfig`).
- Thêm assembly logic mới thì nhớ thêm vào `Tools/LogicTests/LogicTests.csproj` và asmdef của Tests / App (như `PawFit.Economy`).
- Quảng cáo: Editor / bản Dev dùng `MockAdService`, bản Release dùng `NoAdService` (không có quảng cáo). Gắn SDK thật = viết 1 lớp `IAdService` mới thay `NoAdService` trong `GameBootstrap`.
- Compile thử chế độ bản phát hành (không có `UNITY_EDITOR`): `dotnet build Tools/UnityCompileCheck -p:DefineConstants=RELEASE_CHECK -o <thư mục tạm>`.
- Lỗi nhỏ đã biết (ảnh render): da dưới lông đậm hơn lông nên quanh mắt hơi cam. Trong Unity đã dùng shader riêng nên không bị.
